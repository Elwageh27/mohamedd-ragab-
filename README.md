# موقع دوري القسم الرابع — نسخة Google Sheets

هذه النسخة مربوطة برابط Google Apps Script الذي تم إعداده للمشروع. لا تحتاج Firebase.

## ما يعمل في هذه النسخة
- قراءة بيانات البطولة والفرق والترتيب والنتائج من Google Sheets.
- إدخال نتيجة مباراة وحساب النقاط والترتيب تلقائيًا.
- إضافة فريق وتعديل اسمه وحذفه (إذا لم تكن له مباريات مسجلة).
- تعديل إعدادات البطولة وبيانات الكابتن والأسبوع الحالي.
- الاحتفاظ برصيد الأسبوع الرابع الأساسي كما هو محفوظ في الشيت.

## النشر
1. فك ضغط الملف.
2. ارفع محتويات مجلد `league_manager_site` إلى مستودع GitHub الذي تستخدمه للموقع.
3. فعّل GitHub Pages من Settings ثم Pages.
4. افتح رابط الموقع المنشور.

## دخول الإدارة
- اضغط «دخول الإدارة» في الموقع.
- أدخل قيمة `ADMIN_PIN` التي حفظتها في Script Properties داخل Apps Script.
- لا تضع رمز الإدارة داخل ملفات الموقع ولا ترسله لأحد. الرمز يبقى في ذاكرة الصفحة فقط أثناء جلسة الإدارة.
- خادم Apps Script يتحقق من الرمز قبل تنفيذ أي تعديل.

## ملاحظات مهمة
- رابط Apps Script العام يسمح بقراءة بيانات الدوري، لكن عمليات الكتابة تتحقق من `ADMIN_PIN` على الخادم.
- تم تعطيل تبويب المباريات القادمة مؤقتًا لأن نسخة Apps Script الحالية لا تحتوي بعد على ورقة Fixtures. يمكن إضافته في تحديث لاحق.
- سجل الأسابيع الأربعة السابقة محفوظ كرصيد أساسي، وليس كسجل نتائج تفصيلي؛ لذلك حذف نتيجة جديدة لا يمس رصيد الأسابيع الأربعة.
- إذا غيّرت كود Apps Script لاحقًا، يجب نشر إصدار جديد من Manage deployments.


## تحديث لوحة الإدارة (نسخة نوفمبر 2026)

هذه النسخة تضيف:
- التحقق من رمز الإدارة قبل إظهار لوحة التحكم. التحقق يتم عبر رمز عشوائي مؤقت، ولا يتم إرسال رمز الإدارة في عنوان URL.
- زر دخول مسؤول صغير في تذييل الصفحة بدل زر واضح في الشريط العلوي.
- تعديل نتيجة مباراة مسجلة.
- تصحيح الرصيد الأساسي للفريق (بيانات الأسابيع السابقة) مع استمرار إضافة نتائج المباريات الجديدة تلقائيًا.

### مهم جدًا قبل رفع الموقع
1. افتح ملف `Apps_Script_Code.gs` الموجود داخل المجلد.
2. انسخ محتواه كاملًا إلى مشروع Apps Script الحالي مكان الكود القديم، ثم احفظ.
3. من Apps Script اختر **Deploy > Manage deployments**.
4. اضغط القلم بجوار Web app، واختر **New version** ثم **Deploy**. لا تنشئ مشروعًا جديدًا.
5. احتفظ بنفس رابط `/exec` الحالي؛ لا تغيّر رابط API في `app.js`.
6. ارفع ملفات الموقع الجديدة إلى GitHub Pages بعد ذلك.

لا تشارك رمز الإدارة مع أي شخص، ولا تضعه داخل ملفات الموقع.
